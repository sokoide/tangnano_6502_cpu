# Day 19: 周辺機器の統合 (UART, タイマー)

---

🌐 Available languages:
[English](./README.md) | [日本語](./README_ja.md)

## 📜 概要

どんなに優れた CPU でも、外の世界と通信できなければ役に立ちません。今日は、CPU に **UART (シリアル通信)** と **ハードウェア・タイマー** を接続し、**メモリマップド I/O (MMIO)** を介して制御する方法を学びます。

これにより、PC のターミナルに文字を出力したり、正確な時間間隔で処理を行ったりすることができるようになります。

## 🎯 学習目標

-   **メモリマップド I/O (MMIO)**: メモリ番地を周辺機器の制御に割り当てる仕組み。
-   **UART 通信**: シリアルデータの送受信プロトコルとレジスタ制御。
-   **タイマー実装**: 一定クロックごとに値を更新し、ソフトウェアから読み取る仕組み。

## 🏗️ メモリマップの構築（例）

| アドレス範囲    | 対象機器    | 説明                            |
| --------------- | ----------- | ------------------------------- |
| `$0000 - $07FF` | RAM         | ワークエリア (2KB)              |
| `$4000`         | UART TX/RX  | データの送受信レジスタ          |
| `$4001`         | UART Status | 送信完了/受信データありのフラグ |
| `$4010`         | Timer       | ミリ秒単位などのカウンタ        |
| `$8000 - $FFFF` | ROM         | プログラム格納領域              |

## 🛠️ 実装ステップ

1.  **アドレスデコーダーの拡張**:
    -   `top.sv` 等のバス管理部で、特定アドレスへのアクセスを周辺機器モジュールへ振り分けるロジックを書きます。
2.  **UART モジュールの接続**:
    -   `STA $4000` が実行されたら、その値をシリアル信号として物理ピンから出力します。
3.  **タイマーの実装**:
    -   1ms ごとに増えるカウンタを作り、`LDA $4010` でその下位 8 ビットを読み取れるようにします。

## 🧪 動作確認

-   **テストプログラム**:
    ```asm
    LDA #'H'     ; 文字 'H'
    STA $4000    ; UARTから送信
    LDA #'I'     ; 文字 'I'
    STA $4000    ; UARTから送信
    ```
-   **実機 (FPGA)**: USB シリアルアダプタを介して、PC のターミナル（PuTTY や `screen`）に "HI" という文字が表示されることを確認します。

## ハードウェア概念

| 用語      | 説明                                                                          |
| --------- | ----------------------------------------------------------------------------- |
| **FPGA**  | Field-Programmable Gate Array。再構成可能な論理ブロックを持つチップ。         |
| **RTL**   | Register-Transfer Level。レジスタと組み合わせ回路を記述する HDL コード。      |
| **LUT**   | Look-Up Table。小さな真理値表で組み合わせ回路を実装。                         |
| **FF**    | Flip-Flop。クロックエッジで更新される 1 ビットのレジスタ。                    |
| **BSRAM** | Block Static RAM。FPGA 内蔵の専用メモリブロック。                             |
| **PLL**   | Phase-Locked Loop。基準クロックから正確な周波数を生成。                       |
| **FSM**   | Finite State Machine (有限状態機械)。定義された状態を持つ順序回路のパターン。 |

## SystemVerilog キーワード

| 用語              | 説明                                                               |
| ----------------- | ------------------------------------------------------------------ |
| **`logic`**       | ワイヤとレジスタ両方に使える最新のデータ型。`wire`/`reg`より推奨。 |
| **`always_ff`**   | クロックエッジでトリガーされる順序回路ブロック。レジスタを生成。   |
| **`always_comb`** | 組み合わせ回路ブロック。クロック不要、入力に即座に反応。           |
| **`assign`**      | 組み合わせ回路の継続代入（配線）。                                 |
| **`posedge`**     | 信号の立ち上がりエッジ（0→1 遷移）。                               |
| **`negedge`**     | 信号の立ち下がりエッジ（1→0 遷移）。                               |
| **`<=`**          | ノンブロッキング代入。`always_ff`で同時更新に使用。                |
| **`=`**           | ブロッキング代入。`always_comb`やテストベンチで使用。              |

## 開発プロセス

| 用語                 | 説明                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------ |
| **合成 (Synthesis)** | RTL コードを論理プリミティブ（LUT, FF）のネットリストに変換。                        |
| **配置配線 (P&R)**   | 論理を FPGA の物理リソースにマップし配線する。                                       |
| **ビットストリーム** | FPGA に書き込む設定用バイナリファイル。                                              |
| **テストベンチ**     | ハードウェアモジュールをテストするシミュレーション専用コード（ユニットテスト相当）。 |
| **DUT**              | Design Under Test。テストベンチでテスト対象のモジュール。                            |
| **波形 (Waveform)**  | シミュレーション中の信号値の時系列グラフ。                                           |

## 6502 CPU 用語

| 用語                     | 説明                                                             |
| ------------------------ | ---------------------------------------------------------------- |
| **PC**                   | Program Counter。次の命令のアドレスを保持。                      |
| **SP**                   | Stack Pointer。スタックの現在位置を指す。                        |
| **ALU**                  | Arithmetic Logic Unit (算術論理演算装置)。演算と論理操作を実行。 |
| **ゼロページ**           | アドレス`$0000`-`$00FF`。1 バイトアドレスで高速アクセス。        |
| **オペコード**           | Operation code。実行する命令を指定するバイト。                   |
| **アドレッシングモード** | CPU がオペランドのメモリ位置を決定する方法。                     |

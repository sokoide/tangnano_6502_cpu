# 🔌 Board Setup and Configuration (Tang Nano 9K / 20K)

---

🌐 Available languages:
[English](./BOARD_SETUP.md) | [日本語](./BOARD_SETUP_ja.md)

## Overview

The curriculum in this repository supports both the **Tang Nano 9K** and **Tang Nano 20K** FPGA boards from Sipeed.
The two boards differ in their FPGA device family, reset button polarity, and clock configurations. This document summarizes these differences and explains how to configure and build for each target.

---

## 1. Board Specifications Comparison

| Parameter | Tang Nano 9K | Tang Nano 20K |
| :--- | :--- | :--- |
| **FPGA Device** | Gowin GW1NR-9C (`GW1NR-LV9QN88PC6/I5`) | Gowin GW2AR-18C (`GW2AR-LV18QN88PC8/I7`) |
| **LUTs (Logic Cells)** | 8,640 | 20,736 |
| **Embedded BSRAM** | 468 Kbits (26 Block RAMs) | 828 Kbits (46 Block RAMs) |
| **On-board Crystal** | 27 MHz | 27 MHz |
| **Reset Button Polarity** | **Active-High** (High when pressed) | **Active-Low** (Low when pressed) |
| **RTL Reset Connection** | `rst_n = ResetButton;` | `rst_n = !ResetButton;` |
| **Top-Level Constraints** | `tang_nano_9k.cst` | `tang_nano_20k.cst` |
| **Build Target Flag** | `make BOARD=9k` (default) | `make BOARD=20k` |

## 2. Reset Button Polarity

Internal FPGA logic typically uses an **Active-Low Reset (`rst_n`)** (reset when `0`, normal operation when `1`).

- **Tang Nano 9K**:
  - The on-board `ResetButton` (S1) is pulled down; pressing the button inputs `1` (High), and releasing it inputs `0` (Low).
  - Therefore, to connect it to the active-low internal `rst_n`, it is wired directly as `rst_n = ResetButton;` (or matched to the board pull-up configuration).
- **Tang Nano 20K**:
  - The on-board `ResetButton` (S1) is pulled up; pressing the button inputs `0` (Low), and releasing it inputs `1` (High).
  - Therefore, the logic is inverted to generate the internal reset signal: `rst_n = !ResetButton;`.

## 3. Clock Tree and Frequencies

### On-board Oscillator

Both boards receive a base clock from an on-board **27 MHz** crystal oscillator.

### LCD Pixel Clock (9 MHz)

To drive the 480×272 LCD panel (approx. 58 Hz refresh rate), rPLL (PLL9) generates **9 MHz**.

### CPU / Memory Clock

- **Day 04–17**: Both boards run at **40.5 MHz** generated by rPLL40.
- **Day 18 & Day 99**:
  - **Tang Nano 9K**: Operates at **27 MHz** (IDIV=6, FBDIV=6) to ensure robust post-place-and-route setup timing margins.
  - **Tang Nano 20K**: With its faster fabric, it operates at **40.5 MHz** (IDIV=6, FBDIV=9).

### LCD Display Pipeline and CDC (Clock Domain Crossing)

- The VRAM (SDPB) **write port (`clka`)** operates in the CPU/memory clock domain.
- The VRAM (SDPB) **read port (`clkb`)** and the Font ROM (pROM) **read clock (`clk`)** operate synchronously in the **9 MHz pixel clock (`LCD_CLK`)** domain.
- This design prevents zero-margin CDC race conditions between the memory domain and pixel domain, ensuring flicker-free, stable text rendering.

## 4. Tool Paths and Environment Variables

If Gowin EDA is installed in a non-standard path, you can specify tool locations using environment variables when invoking `make`.

### macOS

If Gowin EDA is installed under `/Applications/GowinIDE.app`, it is detected automatically.
To specify paths manually:

```bash
export GWSH=/Applications/GowinIDE.app/Contents/Resources/Gowin_EDA/IDE/bin/gw_sh
export PRG=/Applications/GowinIDE.app/Contents/Resources/Gowin_EDA/Programmer/bin/programmer_cli

# Build and program for 9K
make BOARD=9k download

# Build and program for 20K
make BOARD=20k download
```

### Linux / WSL

Typically installed under `~/Gowin/`:

```bash
export GWSH=$HOME/Gowin/IDE/bin/gw_sh
export PRG=$HOME/Gowin/Programmer/bin/programmer_cli
```

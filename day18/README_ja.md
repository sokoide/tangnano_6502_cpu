# Day 18: 独自拡張命令 (HLT, WVS, CVR, IFO)

---

🌐 Available languages:
[English](./README.md) | [日本語](./README_ja.md)

## 📜 概要

FPGA で CPU を自作する醍醐味の一つは、既存のアーキテクチャにない「自分だけの命令」を追加できることです。今日は、6502 の未使用オペコードを使って、FPGA ハードウェアを直接制御する **カスタム命令** を実装します。

これにより、プログラムから CPU を停止させたり、VRAM の書き込みを制御したりするなどの独自の操作が可能になります。

## 🎯 学習目標

-   **カスタム命令の定義**: 未使用オペコードの活用方法。
-   **ハードウェアとの直結**: 命令実行が CPU 外部のプロセッサ（LCD ドライバ等）に与える影響。
-   **アーキテクチャの柔軟性**: ソフトウェアでハードウェア機能を直接叩く「アクセラレータ」の概念。

## 🏗️ 実装するカスタム命令

| オペコード | ニーモニック | 説明                                                              |
| :--------: | ------------ | ----------------------------------------------------------------- |
|   `0x02`   | `HLT`        | **Halt**: CPU のクロック供給を停止、または無限ループで待機。      |
|   `0x12`   | `WVS`        | **Wait for V-Sync**: 次の垂直同期信号を待つ（画面更新の同期用）。 |
|   `0x22`   | `CVR`        | **Clear VRAM**: VRAM 内容を一括クリア、または特定色で塗りつぶす。 |
|   `0x32`   | `IFO`        | **IO Force**: IO ピンの出力を強制リセット。                       |

## 🛠️ 実装ステップ

1.  **オペコードの割り当て**:
    -   `opcodes.svh` に新しい命令を定義します。6502 で一般的に未使用とされているオペコード（例：`0x02` 系列）を選択します。
2.  **デコーダと実行ロジック**:
    -   `cpu.sv` の `case` 文でこれらの命令を捉えます。
    -   例：`WVS` 命令なら、`v-sync` 信号が入るまで `PC` の更新を一時停止します。
3.  **外部信号の定義**:
    -   `cpu` モジュールのポートに、周辺ハードウェア（画面制御部など）への通知信号を追加し、接続します。

## 🧪 動作確認

-   **テストプログラム**:
    ```asm
    LDA #$AA
    STA $4000  ; 何かを描画
    WVS        ; 画面更新を待つ
    HLT        ; プログラム終了
    ```
-   **実機 (FPGA)**: LCD の描画が同期して行われ、最後に CPU が停止して PC のカウントが止まることを確認します。

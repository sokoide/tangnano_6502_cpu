# Day 20: 最終調整と最適化

---

🌐 Available languages:
[English](./README.md) | [日本語](./README_ja.md)

## 📜 概要

おめでとうございます！ついに 20 日間にわたる 6502 CPU 開発の最終日を迎えました。今日は、これまでに実装した全機能を統合し、**バグの修正**、**タイミングの最適化**、そして **最終的な磨き上げ** を行います。

自作 CPU が安定して動作し、より複雑なプログラムを実行できる準備を整えます。

## 🎯 学習目標

-   **システム統合**: 全モジュール（CPU, Memory, IO）が調和して動くことの最終確認。
-   **タイミング解析**: FPGA 上で正常に動作するための最大動作周波数（Fmax）の考慮。
-   **クリーニング**: コードのコメントや構造を整理し、後で自分や他人が読みやすいようにする。

## 🏗️ 最終チェックリスト

1.  **境界条件の確認**:
    -   ゼロページ跨ぎや、スタックボトム付近での動作が安定しているか。
2.  **命令カバレッジ**:
    -   実装したすべてのオペコードに対して、期待通りのフラグ変化が起きているか（テストスイートの実行）。
3.  **リソース使用率**:
    -   FPGA の LUT や BRAM の使用量をチェックし、無駄なロジックを削減。

## 🛠️ ブラッシュアップのポイント

-   **ステートマシンの効率化**: 無駄な待機サイクル（冗長なステート）がないか見直し、スループットを向上させます。
-   **リセット同期**: システム全体の信頼性を高めるために、リセット信号がすべてのレジスタに正しく行き渡っているか確認します。
-   **ドキュメント整備**: 自分が選んだ MMIO のアドレス表などを README やヘッダーファイルに整理します。

## 🧪 最終テスト

-   **デモプログラム**:
    -   UART から受信した文字を LCD に表示。
    -   タイマーを使って LED を正確に点滅。
    -   サブルーチンを多用した、より高度な演算プログラムの実行。

## 🏁 ゴールに到達！

これで 20 日間の基礎カリキュラムは終了です。あなたは今、**自分の手で作った、実際に動作する CPU** を持っています。
